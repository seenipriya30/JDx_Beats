## ✨ Overview

**JDX Beats** (formerly Tech Haven) is a premium music streaming application built with a focus on immersive UI, real-time data integration, and seamless user experience. Featuring a deep-dark glassmorphic aesthetic, the platform offers everything from globally trending charts to personalized user playlists.

## 🚀 Key Features

### 🔍 Smart Global Search
Find your favorite music instantly. Our real-time search engine filters through albums, artists, and languages as you type, providing immediate feedback.

### 📈 Live Trending Charts
Stay ahead of the curve with real-time trending English and Tamil music charts, fetched directly via the Apple iTunes RSS API.

### 🎭 Immersive UI/UX
- **Ambient Living Backgrounds**: The site's atmosphere changes dynamically based on the album art of the currently playing track.
- **3D Parallax Effects**: Interactive tilt effects on album cards for a tactile, premium feel.
- **Glassmorphism**: A sleek, modern design language with blurred panels and neon accents.

### 🎵 Pro Audio Engine
- **Persistent Global Player**: Music never stops. The mini-player stays active across all routes.
- **Simulated Waveform Visualizer**: A canvas-based real-time visualizer that reacts to the playback state.
- **Premium Playback Controls**: High-fidelity audio with seamless transitions.

### 📂 User-Driven Library
- **Luxury Playlist Management**: Create and manage custom music collections with a sophisticated modal-first workflow.
- **Favorites Hub**: Quick access to your top-tier tracks, synced in real-time with Firebase Firestore.

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite, Tailwind CSS (v4)
- **Animations**: Framer Motion, React Parallax Tilt
- **Backend**: Firebase (Authentication & Firestore)
- **API**: Apple iTunes RSS API
- **Visuals**: Lucide Icons, React Icons, Canvas API

## ⚙️ Installation & Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/seenipriya30/JDx_Beats.git
   ```

2. **Install dependencies**:
   ```bash
   cd tech_haven_music
   npm install
   ```

3. **Set up Firebase**:
   Create a `.env` file in the root and add your Firebase configuration.

4. **Run the development server**:
   ```bash
   npm run dev
   ```
